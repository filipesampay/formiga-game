# Formigas no Açúcar 🐜

Jogo web (sem instalar, roda no Safari do iPhone). Quadro de cubos de açúcar coloridos; escolha até 4 caixas de formigas por vez. Cada caixa solta N formigas da sua cor, que só levam cubos com caminho livre até o buraco. Travou com os 4 slots cheios = fim de jogo.

- Jogar: https://filipesampay.github.io/formiga-game/
- Local: `python3 -m http.server` e abrir http://localhost:8000
- Testes: `node --test tests/`
